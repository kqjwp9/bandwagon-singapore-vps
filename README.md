## 新加坡机房实测表现如何？

汇总第三方对迁移期 SG 机房的实测数据，几个关键维度如下：

- 延迟：国内三网平均 60–90ms，对新加坡到大陆的物理距离属正常水平。比香港机房（一般 10–30ms）高，但比美西机房少了将近 100ms 的物理延迟。
- 路由：回程三网全部走 CN2 GIA，电信经 59.43 骨干段回国内；去程电信走 CN2，联通走 NTT，移动先到香港 CMI 再转 NTT。回程优化明显，去程是常规国际线路。
- 速度：新加坡本地 Speedtest 上下行 9312/8177 Mbps，接近跑满万兆端口；国内三网下行大多在 1.4–2.7Gbps。测试中北京联通下行出现过 6Mbps 的异常低值——联通去程走 NTT，部分时段可能有波动，联通用户建议长期观察。
- 丢包：测试期国内三网及海外节点全部 0 丢包。CN2 GIA 本身按低丢包专线设计，加上测试期机房用户不多、线路资源充裕，这项数据有客观加成，长期表现以实际使用为准。
- 硬件与流媒体：AMD CPU 加 NVMe SSD，和香港、东京机房同一档次。Netflix 仅解锁原创内容；YouTube Premium 正常（新加坡区）；TikTok 可用；ChatGPT 可正常访问（识别为美国区）；爱奇艺国际版可以，B站大陆区不行。

概括一下：线路和带宽是强项，流媒体解锁中规中矩。买它图的是延迟、稳定性和大带宽，图流媒体全解锁的话它给不了。
